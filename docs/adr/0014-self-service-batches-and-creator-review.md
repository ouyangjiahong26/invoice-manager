# ADR-0014: 自助组由成员建批并审批自己的批次

日期：2026-10-24　状态：已接受

## 背景

有的组希望成员各自处理自己的报销，不再由管理员统一建批和审核。其余组继续保持管理员集中管理。原模型只有管理员能建批和改审核状态，批次也没有创建人，无法支持“谁建批谁审批”。

## 决策

- 新增组设置 `GroupSettings`，与 `auth.Group` 一对一，字段 `self_service` 表示是否开启成员自助。后台组页面勾选开关，默认关闭。
- `Batch` 增加 `created_by`，记录创建人。历史批次保持空值，仍只由管理员审核。
- 开启自助的组里，成员可以创建批次。成员提交的条目进入自己最新创建的批次，其他组仍进入组最新批次。批量提交同理。
- 批次创建人可审核自己创建批次中的条目，只能改审核状态，批语必填。不能改付款人，不能编辑或删除他人条目，不能调序或存档批次。
- 管理员仍可审核全部批次，组设置关闭后成员立即失去建批和审核权限。
- 同组成员查看彼此条目的范围不变，未开启自助的组行为不变。

## 后果

- 自助组成员没有自己的批次时不能提交条目，页面提示先建批。
- 看板批次下拉显示创建人，避免同名批次难以区分。
- 管理员后台可随时关闭某组的自助，不需要改代码。
- 审批仍只覆盖状态，不扩展到付款人、删除或存档。以后要扩大权限需另立决策。
